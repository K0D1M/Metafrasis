# Μετάφρασις

Πλατφόρμα διαχείρισης μεταφράσεων για μικρές ομάδες που τοπικοποιούν βιντεοπαιχνίδια.
Τα κείμενα του παιχνιδιού ζουν σε αρχεία JSON· η ομάδα τα μεταφράζει σε κοινό περιβάλλον,
σχολιάζει ανά κείμενο και παρακολουθεί την πρόοδο ανά κεφάλαιο.

Web εφαρμογή — τρέχει σε browser, άρα δουλεύει σε Windows και macOS χωρίς αλλαγές.

## Απαιτήσεις

- Node.js 20+ (δοκιμασμένο σε v24.21.0)

## Ξεκίνημα

```bash
npm install
npm run db:migrate -w server   # δημιουργεί τη βάση SQLite
npm run db:seed -w server      # προαιρετικά: δοκιμαστικά δεδομένα
npm run dev                    # server στο :3001, client στο :5173
```

Άνοιξε <http://localhost:5173>.

Λογαριασμοί από το seed:

| Ρόλος        | Email                        | Κωδικός       |
| ------------ | ---------------------------- | ------------- |
| Διαχειριστής | `manager@metafrasis.dev`     | `password123` |
| Μεταφραστής  | `translator@metafrasis.dev`  | `password123` |

## Τι υπάρχει ήδη

- **Λογαριασμοί και ρόλοι** — Διαχειριστής / Μεταφραστής, με έλεγχο στον server
- **Σύνδεση με email ή όνομα χρήστη** — και τα δύο είναι μοναδικά στη βάση
- **Επαναφορά κωδικού** — «Ξέχασες τον κωδικό;» στη σελίδα σύνδεσης· χωρίς SMTP σε αυτή τη
  φάση, ο σύνδεσμος εμφανίζεται στην οθόνη (ίδιο μοτίβο με τις προσκλήσεις μελών), λήγει σε
  1 ώρα και χρησιμοποιείται μία μόνο φορά
- **Δημιουργία project** — όνομα, γλώσσα πηγής, γλώσσες στόχου
- **Επεξεργαστής κειμένων** — πρωτότυπο δίπλα σε μετάφραση, με σχόλια και απαντήσεις
- **Πρόοδος** — μπάρα ανά project και ανά αρχείο
- **Θέμα** — φωτεινό / σκοτεινό, με προεπιλογή από το σύστημα

## Πώς διαβάζονται τα αρχεία JSON

Το `server/src/services/jsonFlatten.ts` μετατρέπει εμφωλευμένο JSON σε επίπεδη λίστα
κειμένων και το ξαναχτίζει στην ακριβή αρχική δομή για την εξαγωγή.

```json
{ "chapter1": { "intro": { "line1": "Hello" } } }
```

γίνεται ένα κείμενο με κλειδί `chapter1.intro.line1`. Κλειδιά που περιέχουν τελεία ή
backslash γίνονται escape, ώστε η διαδρομή να αποκωδικοποιείται μονοσήμαντα.

Αυτό το round-trip είναι το πιο κρίσιμο σημείο του project: αν χαλάσει, κάθε εξαγωγή
καταστρέφει σιωπηλά τα αρχεία του παιχνιδιού. Γι' αυτό καλύπτεται από τα πρώτα tests
που γράφτηκαν.

## Ενημέρωση αρχείου — τι γίνεται με τις μεταφράσεις

Μια Ενημέρωση **δεν διαγράφει ποτέ μετάφραση**. Η σύγκριση γίνεται ανά διαδρομή κλειδιού:

| Κατάσταση                     | Τι συμβαίνει                                        |
| ----------------------------- | --------------------------------------------------- |
| Κλειδί και στις δύο εκδόσεις  | Η μετάφραση διατηρείται                             |
| Άλλαξε το πρωτότυπο           | Η μετάφραση διατηρείται, με σήμανση «Χρειάζεται έλεγχος» |
| Νέο κλειδί                    | Προστίθεται αμετάφραστο                             |
| Λείπει από τη νέα έκδοση      | Σημαίνεται ως removed, **δεν διαγράφεται**          |

Το τελευταίο είναι σκόπιμο: ένα κλειδί που έφυγε μπορεί να επανέλθει σε επόμενη
αναθεώρηση, και μαζί του η μετάφραση που είχε ήδη γίνει.

## Έλεγχοι

```bash
npm test     # flatten round-trip, διαφορές Ενημέρωσης, μαθηματικά προόδου, HTTP headers
```

Ένα από τα tests αξίζει αναφορά: το `contentDisposition.test.ts`. Οι τιμές των HTTP
headers είναι Latin-1, οπότε ένα ελληνικό όνομα project στο `Content-Disposition`
έριχνε ολόκληρο τον διακομιστή κατά τη λήψη του `.zip`. Το `attachmentHeader()` δίνει
ASCII fallback μαζί με το πραγματικό όνομα σε `filename*` (RFC 5987), και ο διακομιστής
πλέον καταγράφει τις ανεπιτήρητες εξαιρέσεις αντί να τερματίζει.

## Βάση δεδομένων

SQLite μέσω Prisma, σε ένα αρχείο (`server/prisma/dev.db`). Χωρίς εγκατάσταση, χωρίς συνδρομή.

Για μετάβαση σε Postgres (π.χ. Supabase): άλλαξε το `DATABASE_URL` στο `server/.env`,
βάλε `provider = "postgresql"` στο `schema.prisma` και τρέξε `npx prisma migrate deploy`.
Ο κώδικας της εφαρμογής δεν αλλάζει.
